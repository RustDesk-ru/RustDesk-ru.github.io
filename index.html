01 / ЗНАКОМСТВО С ПРОЕКТОМ

Один проект.
Все важные детали.

RustDesk — open-source программа удалённого рабочего стола, независимая альтернатива TeamViewer и AnyDesk. Эта страница объединяет знакомство с проектом, сведения о сборке и понятный путь к загрузке.

01
REMOTE ACCESS

Доступ без границ

Клиент RustDesk соединяет устройства через ID и одноразовый пароль. Трансляция NAT выполняется без проброса портов — как в публичной сети, так и на собственном сервере.

05 / БАЗА ЗНАНИЙ

Остались
вопросы?

Главное о RustDesk — клиенте, сервере и загрузке.

Вернуться к файлу ↗
Что такое RustDesk?

RustDesk — программа удалённого рабочего стола с открытым исходным кодом, позиционируемая как альтернатива TeamViewer и AnyDesk. Клиент работает на Windows, macOS, Linux и Android, а также есть веб-клиент. Возможности конкретной сборки описаны в её релизе.

Где скачать клиент RustDesk?

Перейди к карточке загрузки на этой странице. Кнопка «Скачать RustDesk» открывает опубликованный файл клиента, а «Открыть релиз» — описание выпуска на GitHub. Если файл ещё не добавлен, страница показывает статус и сообщает, что ссылка появится позже.

Нужен ли свой сервер?

Нет: клиент работает через публичную сеть RustDesk без настройки. Но RustDesk Server (hbbs — сервер рандеву, hbbr — реле) можно развернуть самостоятельно — в Docker, на VPS или в локальной сети. Тогда все соединения проходят только через вашу инфраструктуру.

Какие порты использует сервер hbbs/hbbr?

Базовый набор: TCP 21114–21119 и UDP 21116. Точный перечень зависит от выпуска сервера и схемы развёртывания — сверяйся с документацией RustDesk для своей версии.

Безопасно ли соединение?

RustDesk использует сквозное шифрование сессий, а при собственном сервере — ключ подключения (public key hbbs). Исходный код открыт, поэтому механизм шифрования можно изучить самостоятельно. Размещение кода на GitHub само по себе не заменяет независимый аудит.

Зачем нужна контрольная сумма SHA-256?

SHA-256 — цифровой отпечаток файла. Если хеш загрузки совпадает с опубликованным значением, это помогает подтвердить совпадение файлов. Контрольная сумма не является отчётом о проверке безопасности клиента.

Как подключиться к удалённому компьютеру?

Установи клиент на оба устройства, запомни ID и одноразовый пароль удалённой машины (или задай постоянный пароль в настройках), введи ID на своём компьютере и подтверди подключение. Для работы через свой сервер укажи ID сервера и ключ в настройках клиента.

Связан ли проект с TeamViewer или AnyDesk?

RustDesk — независимый open-source проект. Эта страница не является сайтом TeamViewer, AnyDesk или RustDesk Inc. и не заявляет о партнёрстве с ними.
